## Contributing Examples

When adding new examples:

1. **Documentation:** Include clear comments and usage instructions
2. **Testing:** Verify examples work with the current codebase
3. **Safety:** Ensure examples don't risk hardware damage
4. **Naming:** Use descriptive filenames with clear purposes
